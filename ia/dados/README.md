
# Dados do protótipo de IA

Esta pasta contém os dados utilizados na demonstração de detecção de anomalias.

## Arquivos previstos

- `leituras.csv`: leituras de entrada exportadas ou preparadas para análise.
- `resultado_anomalias.csv`: arquivo produzido pelo script de análise.

O CSV de entrada deve conter `pet_id`, `tipo`, `valor` e `data_registro`.

Os dados podem ser simulados para os testes acadêmicos. Quando forem usados
dados simulados, isso deve ser informado na apresentação dos resultados.

Não interpretar os resultados como diagnóstico veterinário.
